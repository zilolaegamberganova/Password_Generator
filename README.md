# 🔒 Password Generator Web App

A clean, responsive, and minimalist Password Generator web application built with HTML, CSS, and JavaScript. It features a modern split-screen layout with custom illustrations and generates short, normal, and long passwords dynamically.

## 🚀 Features
- **Split-Screen Design:** 50/50 layout combining a clean visual illustration and functional form elements.
- **Multiple Password Lengths:** Instantly generates short, medium, and long passwords with a single click.
- **Pure Vanilla JS:** Built using native JavaScript randomization logic (`Math.random()`).
- **Responsive & Clean UI:** Styled with CSS Flexbox and modern design principles.

## 🛠️ Technologies Used
- **HTML5** — Structure and layout
- **CSS3** — Styling, Flexbox, and visual aesthetics
- **JavaScript (ES6)** — Password generation logic and DOM manipulation
